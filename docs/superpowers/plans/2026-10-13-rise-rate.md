# Rise Rate Calculator Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** In the spectrometer window the operator picks a detector, presses Start, watches the rate settle and presses Stop, and gets the rise rate by endpoints and by a straight-line fit with its uncertainty, marked on the chart and kept in a table for the session.

**Architecture:** The arithmetic and the accumulation of one detector's readings are plain functions and a small class with no Qt widgets (`rise_rate.hpp`). A `RiseRatePanel` widget owns a run, shows the numbers and the table, and says when a run starts and stops. The spectrometer window puts the panel in its Controls dock, hands it every reading it already receives, and turns the panel's start and stop times into vertical marks on the strip chart.

**Tech Stack:** C++20, Qt 6 Widgets, QCustomPlot, QtTest.

**Spec:** `docs/superpowers/specs/2026-10-13-rise-rate-design.md`. Section numbers below refer to it.

## Global Constraints

- Nothing is sent to the spectrometer. The panel only listens.
- No clock is read: a duration is the difference of two readings' `ts`, and the wall time of a result comes from the function the window was given, or is blank.
- Qt code: a parent owns its child. `const` by default, `[[nodiscard]]` on results that must not be dropped.
- Each task is one commit, Conventional Commits with scope `ui`. Before each: `python3 tools/quality_check.py --build-dir build/dev-ui` (exit 0) and the tests the task names, built with the `dev-ui` preset. Before the branch lands: full `cmake --build --preset dev-ui`, `ctest --preset dev-ui`, `python3 tools/compiler_sweep.py --build-dir build/dev-ui`.

### Task 3: The panel

**Files:** `apps/pychron-ui/src/rise_rate_panel.hpp`, `.cpp`, `apps/pychron-ui/CMakeLists.txt`, `tests/ui/test_rise_rate.cpp`

```cpp
class RiseRatePanel : public QWidget {
  Q_OBJECT
 public:
  explicit RiseRatePanel(std::vector<DetectorSeries> detectors, QWidget* parent = nullptr);
  void on_reading(const spectrometer::IntensityReading& reading);
  void set_detector(const QString& name);                  // ignored while running or when unknown
  void set_isotope(const std::string& detector, const QString& isotope);
  void set_wall_clock(std::function<QDateTime()> now);
  void toggle();                                           // the Start / Stop button
  [[nodiscard]] bool running() const;
  // For tests.
  [[nodiscard]] QTableWidget* results() const;
  [[nodiscard]] QString live_text() const;
  [[nodiscard]] QString status_text() const;
  [[nodiscard]] QComboBox* detector_box() const;
  [[nodiscard]] QString copy_text() const;                 // what Copy puts on the clipboard

  void started(pychron::TimePoint at);                     // the first reading of the run
  void stopped(pychron::TimePoint at);                     // its last; only when a result was made

};
```
