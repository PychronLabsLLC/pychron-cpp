# Vision Library Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `libs/vision`: target finding, autocenter and dragonfly as step-function controllers, camera-to-stage calibration, and frame sources for test and replay.

**Architecture:** A pure library on `pychron::core`. Finders turn a grey frame into ranked targets; controllers turn frames into a decision (`Move`, `Hold`, `Converged`, ...) and never touch a stage, a clock or a thread. A dependency-free core is always built; an OpenCV-backed legacy finder and capture source are optional.

**Tech Stack:** C++20, CMake, GoogleTest, `pychron::core` (`Result`, `fail`, `ErrorKind`, `TimePoint`, `Duration`, `ManualClock`), toml++ (via core), optional OpenCV (`core`, `imgproc`, `videoio`).

**Spec:** `docs/superpowers/specs/2026-10-03-vision-design.md`. Background: `docs/superpowers/specs/2026-10-03-legacy-laser-survey.md` §7.

## Global Constraints

- Namespace `pychron::vision`. Public headers in `libs/vision/include/pychron/vision/`, sources in `libs/vision/src/`, tests in `tests/vision/test_<component>.cpp`.
- `libs/vision` links `pychron::core` only. No Qt, no devices, no threads, no sleeps.
- Sources and tests are globbed, as in `libs/reduction/CMakeLists.txt` and `tests/reduction/CMakeLists.txt`.
- Warnings are errors (`pychron_set_warnings`). Must pass clang + ASan/UBSan, gcc 14 and MSVC.
- OpenCV headers appear only in `src/legacy_finder.cpp` and `src/opencv_source.cpp`, included as SYSTEM. Never in a public header.
- Errors use `pychron::Result<T>` and `pychron::fail(ErrorKind, what)`. Bad arguments and bad files: `ErrorKind::Config`. File read/write failures: `ErrorKind::Io`. Stale frames: `ErrorKind::Protocol`.
- Tests are deterministic: seeded generator, no wall clock.
- Spec defaults, verbatim: saturation threshold 0.75; move threshold 0.033 mm; perimeter radius 2.5 mm; spiral base 0.5 mm; max step 0.5 mm; hole radius tolerance 0.35; hole circularity >= 0.6; glow fraction 0.5; glow minimum area 9 px; autocenter tolerance 0.03 mm, max iterations 4, max total 1.0 mm, frames per step 3; miss frames before search 3; square spiral growth 1.1.
- Commit after each task on the working branch. Do not open pull requests. Merge to `main` and push only after the last task, with `main` rebased on `origin/main` and the full suite passing.

## Review Focus

1. **16-bit frames.** A 12-bit camera frame (`pixel_depth = 4095`) must give the same centre and the same saturation (0..1) as the same scene at 8 bits. Tests in Tasks 3 and 6.
2. **Uniform frames.** All-black, all-white and constant-grey frames must return no target without dividing by zero or thresholding noise into a blob. Test in Task 3.
3. **Region of interest at the frame border.** A crop or mask that extends past the frame must clamp, not read out of bounds. Tests in Tasks 1 and 3.
4. **Empty and invalid input to controllers.** An empty frame span, a non-positive radius, or a singular `CameraStageMap` must produce `Failed`/an error, not a crash or a NaN move. Tests in Tasks 4, 5 and 6.
5. **Malformed fixture files.** Truncated PGM, PGM with comments, 16-bit big-endian PGM, and a `case.toml` naming a missing file must each give a clear `Result` error or load correctly. Test in Task 8.

  int width = 200, height = 200; std::uint16_t pixel_depth = 255;

  double background = 0.02, noise = 0.0; bool crosshair = false;
  std::uint32_t seed = 1;
};

std::pair<Frame, Truth> render(const HoleScene&, Vec2 stage_mm);

 public:
  virtual ~IFrameSource() = default;
  virtual Result<Frame> grab() = 0;
  virtual FrameInfo info() const = 0;
};
class SyntheticSource final : public IFrameSource {
 public:
  using StageFn = std::function<Vec2()>;
  using ClockFn = std::function<TimePoint()>;

  Truth last_truth() const;
};

### Task 4: CameraStageMap

**Files:**
- Create: `include/pychron/vision/calibration.hpp`; `src/calibration.cpp`
- Test: `tests/vision/test_calibration.cpp`

**Interfaces — Produces:**

```cpp
struct JogPair { Vec2 stage_delta_mm; Vec2 image_delta_px; };
struct CameraStageMap {
  double m[2][2] = {{1, 0}, {0, 1}};   // px -> mm, stage frame
  double residual_mm = 0;
  Vec2 to_mm(Vec2 px) const;
  bool valid() const;                  // finite and |det| > 1e-12
  static CameraStageMap from_scale(double px_per_mm, bool flip_x, bool flip_y);
  static Result<CameraStageMap> solve(std::span<const JogPair>);
  std::string to_toml() const;
  static Result<CameraStageMap> from_toml(std::string_view);
};
```

`to_mm` maps the image offset of a target to the stage move that centres it. With the Task 2 convention, the centring move for an image offset `(dx, dy)` px is `(dx, -dy) / px_per_mm`; `from_scale(p, false, true)` must produce exactly that. `solve`: a jog of `stage_delta_mm` shifts a fixed target by `image_delta_px`, so the centring map `M` satisfies `M * image_delta_px = -stage_delta_mm`; solve by least squares. TOML: `m = [[a, b], [c, d]]`, `residual_mm = r`.

**Files:**
- Create: `include/pychron/vision/spiral.hpp`, `dragonfly.hpp`; `src/spiral.cpp`, `dragonfly.cpp`

**Interfaces — Consumes:** `ITargetFinder`, `CameraStageMap`, `GlowScene`, `sim_loop.hpp`. **Produces:**

```cpp
enum class SpiralKind { Hexagon, Square };
class Spiral {
 public:
  Spiral(SpiralKind, double base_mm, double square_growth = 1.1);
  Vec2 next();          // offsets from the anchor; first call is the first ring point, never {0,0}
  void reset();
};

struct DragonflyParams {
  Duration total_duration{};
  double perimeter_radius_mm = 2.5;
  double saturation_threshold = 0.75;
  double aggressiveness = 1.0;
  double move_threshold_mm = 0.033;
  double max_step_mm = 0.5;
  SpiralKind spiral = SpiralKind::Hexagon;
  double spiral_base_mm = 0.5;
  int    frames_per_step = 1;
  int    miss_frames_before_search = 3;
  double target_radius_mm = 0.5;   // sizes crop (2.5x) and mask (1.05x)
};
struct DragonflyStep {
  enum class Action { Hold, Move, Done } action;
  Vec2 target_mm;                  // offset from the start position
  double saturation;
  enum class Reason { Saturated, Deadband, Track, Search, PerimeterClamp,
                      Miss, Elapsed, Invalid } reason;
};
class Dragonfly {
 public:
  Dragonfly(ITargetFinder&, CameraStageMap, double px_per_mm, DragonflyParams);
  void start(TimePoint now, Vec2 stage_pos_mm);
  Result<DragonflyStep> step(std::span<const FrameView>, TimePoint now, Vec2 stage_pos_mm);
};
```

Rules: spec §8 and §9. Hexagon: ring `k >= 1` has `6k` points on the hexagon of circumradius `k * base`, walked edge by edge, starting at angle 0. Square: side grows by `square_growth` per lap, four corners per lap, starting +x. `Miss` is `Hold` while misses are below `miss_frames_before_search`. A frame whose `timestamp` is earlier than the time of the previous `Move` decision gives `fail(ErrorKind::Protocol, "stale frame")`. `step` before `start` gives `Reason::Invalid`, `Hold`.
